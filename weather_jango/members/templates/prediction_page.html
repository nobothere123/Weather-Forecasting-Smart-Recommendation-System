📌 Project Overview

This Weather Prediction System is designed to collect real-time weather data, process historical patterns, and generate accurate forecasts using machine learning models. The platform integrates Large Language Models (LLMs) via Ollama to provide human-like explanations and intelligent weather insights.

⚙️ Technologies Used

🐍 Python

Core programming language used for data processing, ETL pipelines, model training, API development, and automation tasks.

🌐 Django

Used for backend management, admin dashboard, user authentication, and integration with frontend templates.

🤖 Scikit-learn

Machine learning models such as Random Forest and Regression algorithms are used to predict temperature, humidity, and weather trends.

🧠 Ollama (LLM)

Integrated local Large Language Models to analyze prediction outputs and generate natural-language weather explanations and insights.

📊 Data Engineering

ETL pipelines ingest weather data from public APIs, store raw and processed data, and perform feature engineering for time-series forecasting.

🔍 Key Features

✔ Real-time weather data ingestion
✔ Machine learning-based temperature prediction
✔ AI-powered weather explanations using Ollama
✔ REST APIs with FastAPI
✔ Clean and scalable project architecture
✔ Deployment-ready cloud structure
